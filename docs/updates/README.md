## Update Policy

When adding update documentation:

1. **Date the update** - Use `YYYY-MM-DD` format or month/year
2. **Mark severity** - Use ⚠️ CRITICAL, 🔔 IMPORTANT, or ℹ️ INFO
3. **Include migration steps** - Provide clear upgrade path
4. **List affected features** - Be specific about what changes
5. **Add to this README** - Keep the index updated

## Notification Channels
